SECURE_CHECK_DETAILED – A Python-SQL Digital Ledger for Police Post Logs - Description
SecureCheck is a real-time digital ledger system designed to modernize police post logging and monitoring using a combination of Python, SQL (MySQL), and Streamlit. This project enables efficient tracking, querying, and visualization of law enforcement activities, particularly traffic stops, by integrating a structured database with an interactive web dashboard.
Import and store traffic stop data securely in a MySQL database
Built with Streamlit, allowing users to run predefined complex SQL queries via a simple UI.
Supports subqueries, joins, and window functions to generate insights on violations, demographics, vehicle details, and time-based trends.
Organized headers, dropdown filters, and one-click query execution ensure clarity and usability.
Includes PDF cheat sheets and troubleshooting guides for tools like MySQL, XAMPP, and Streamlit.
To provide a reliable, accessible digital platform for law enforcement personnel to review and analyze post logs efficiently, enhancing transparency and operational insight.
